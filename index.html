GUIA HEXSTRIKE — TODAS AS FERRAMENTAS

Servidor: http://127.0.0.1:8888 · Método: POST + JSON · Alvo dos exemplos: sempre local/laboratório (127.0.0.1, 10.0.0.x) — substitua pelo alvo autorizado do seu teste.

Regra de ouro: cada rota aceita campos JSON específicos. Antes de inventar campos, descubra a implementação real: 
grep -n "api/tools/NOME" hexstrike_server.py
sed -n 'LINHA,LINHA+40p' hexstrike_server.py

Base — verificar servidor e listar rotas

curl -s http://127.0.0.1:8888/health
grep -nE '@app\.route' ~/cerebrocaine/hexstrike-ai/hexstrike_server.py | head -100
curl -s -X POST http://127.0.0.1:8888/api/command \
  -H "Content-Type: application/json" \
  -d '{"command":"echo teste"}'

1. Nmap — recon e varredura

reconrede

Usos: descoberta de hosts, portas, versões de serviço, scripts NSE.

curl -sS -X POST http://127.0.0.1:8888/api/tools/nmap \
  -H "Content-Type: application/json" \
  -d '{"target":"127.0.0.1","scan_type":"-sV","ports":"80,443"}'
curl -sS -X POST http://127.0.0.1:8888/api/tools/nmap \
  -H "Content-Type: application/json" \
  -d '{"target":"10.0.0.0/24","scan_type":"-sn","ports":""}'
curl -sS -X POST http://127.0.0.1:8888/api/tools/nmap \
  -H "Content-Type: application/json" \
  -d '{"target":"10.0.0.5","scan_type":"-sV --script vuln","ports":"1-1000"}'

Dica de scan_type: -sV versões · -sn só hosts vivos · -sU UDP · -O SO · -A agressivo.

5. SQLmap — exploração de SQL injection

curl -sS -X POST http://127.0.0.1:8888/api/tools/sqlmap \
  -H "Content-Type: application/json" \
  -d '{"url":"http://127.0.0.1:8080/item.php?id=1"}'

  -H "Content-Type: application/json" \

--forms detecta formulários · -r arquivo.txt usa requisição salva do Burp · --batch responde tudo automaticamente (só em lab).

Workflow completo — recon até exploit (ordem recomendada)

1. Nmap -sV        -> quais portas/servicos existem
2. Nmap --script   -> vulnerabilidades conhecidas dos servicos
3. Dirb/FFUF       -> diretorios e endpoints escondidos
4. Nikto           -> misconfigurations do servidor web
5. SQLmap          -> testar parametros para injecao
6. Hydra           -> teste de credenciais (apenas com autorizacao)
7. John/Hashcat    -> hashes capturados em lab
8. Metasploit      -> exploit confirmado com versao vulneravel

Dicas gerais

  • Timeout do server é 300s: tarefas longas (rockyou inteiro, amass full) estouram. Rode em chunks ou direto no terminal.
  • Ferramenta ausente: a resposta vem com erro no stderr. Confira com command -v ferramenta e instale.
  • Cache: requisições idênticas podem vir do cache; adicione um parâmetro variável ou limpe o cache via /api/cache/stats para testes repetidos.
  • Monitoramento: GET /api/processes/list mostra processos em execução; POST /api/processes/terminate/<pid> encerra.
  • Escopo: todos os exemplos apontam para localhost/lab. Substituir o alvo sem autorização explícita é ilegal em quase toda jurisdição.
